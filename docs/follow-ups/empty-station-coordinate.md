# 빈 문자열 좌표가 (0,0) 위치로 변환됨

- 증상: 오피넷이 `GIS_X_COOR`/`GIS_Y_COOR`를 빈 문자열로 주면, 그 주유소의 지도 링크가 한국 밖의 엉뚱한 위치를 가리킨다.
- 근거: `features/stations/search-nearby-stations.ts`의 `toWgs84`가 `null`/`undefined`만 걸러내고, `Number("")`는 0이라 유한값 검사를 통과한다 (2026-10-22 코드 리뷰 지적).
- 관찰: 강남역 기준 실제 응답 19곳은 모두 정상 좌표였다. 빈 문자열 좌표는 아직 관찰하지 못했다.
- 다음 단계: 빈 문자열과 0 좌표도 "위치 없음"으로 처리하고, route 테스트에 해당 경우를 추가한다.
