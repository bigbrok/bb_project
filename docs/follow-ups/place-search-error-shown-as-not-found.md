# 장소 검색 실패가 "찾지 못함"으로 보임

- 증상(추정): 카카오 장소·주소 검색이 `ERROR` 상태(호출 한도 초과, 네트워크 실패 등)로 끝나도 화면에는 "'입력값' 위치를 찾지 못했습니다."가 나온다. 사용자는 그런 장소가 없다고 오해할 수 있다.
- 근거: `features/stations/kakao-maps.ts`의 `findPlace`가 `OK`가 아닌 상태를 모두 결과 없음(`null`)으로 처리한다 (2026-10-22 코드 리뷰 지적).
- 관찰: 카카오 키가 없어 실제 검색 오류는 재현하지 못했다.
- 다음 단계: `ZERO_RESULT`와 `ERROR`를 구분해 돌려주고, 오류일 때는 "잠시 후 다시 조회해 주세요" 같은 안내를 보여 준다. 테스트의 가짜 SDK에 `ERROR` 응답을 추가한다.
