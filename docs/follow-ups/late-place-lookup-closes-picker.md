# 늦게 끝난 장소 조회가 위치 고르기 화면을 닫음

- 증상(추정): 제목 아래 장소 조회를 보낸 직후 "위치 바꾸기"를 누르면, 조회 응답이 늦게 도착하면서 그 장소로 주유소 검색이 시작되고 방금 연 위치 고르기 화면이 목록으로 바뀐다.
- 근거: `features/places/place-search-form.tsx`가 폼이 사라진(unmount) 뒤에도 응답이 오면 `onFound`를 부른다. Nominatim 초당 1회 제한 때문에 응답이 1초 가까이 늦을 수 있다 (2026-10-22 코드 리뷰 지적, 코드로 확인).
- 관찰: 실제 화면에서는 재현하지 않았다.
- 다음 단계: 폼이 사라질 때 진행 중인 조회를 무시하거나 `AbortController`로 취소하고, 위치 고르기 중에는 늦은 결과를 버린다.
