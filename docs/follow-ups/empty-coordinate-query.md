# 빈 좌표 쿼리가 400 대신 (0,0) 검색으로 처리됨

- 증상: `GET /api/stations?lat=&lng=`가 `invalid_query`(400)를 돌려주지 않고 좌표 (0,0)으로 오피넷을 검색한다.
- 근거: `app/api/stations/route.ts`에서 `Number("")`가 0이 되어 `Number.isFinite` 검사를 통과한다 (2026-10-22 코드 리뷰 지적).
- 영향: 화면은 항상 숫자 좌표를 보내므로 일반 사용 경로에서는 발생하지 않는다. API를 직접 호출할 때만 해당된다.
- 다음 단계: 빈 문자열을 숫자로 바꾸기 전에 걸러 400을 돌려주고, route 테스트에 `lat=&lng=` 경우를 추가한다.
