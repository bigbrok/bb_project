# "현재 위치로 다시 시도" 중 부제목이 잠깐 현재 위치로 바뀜

- 증상: 위치 권한이 계속 없는 상태에서 "현재 위치로 다시 시도"를 누르면, 검색하는 동안 부제목이 "현재 위치 반경 2km"로 바뀌고 마곡나루역 안내와 버튼이 사라졌다가, 실패하면 다시 "마곡나루역 반경 2km"로 돌아온다.
- 근거: `features/stations/station-finder.tsx`의 `searchFrom(CURRENT_POSITION)`이 위치를 얻기 전에 `origin`을 `current`로 바꾼다 (2026-10-22 코드 리뷰 지적, 코드로 확인).
- 영향: 검색이 끝나면 올바른 기준으로 돌아오므로 결과는 맞다. 로딩 중 잠깐 잘못된 기준이 보인다.
- 다음 단계: 다시 시도할 때는 `origin`을 바로 바꾸지 않고 검색 결과가 돌려준 `origin`만 반영한다.
