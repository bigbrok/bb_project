# 도메인 미등록 시 위치 고르기 지도가 안내 없이 비어 보일 수 있음

- 증상(추정): 카카오 JavaScript 키는 맞지만 현재 도메인이 SDK 도메인으로 등록되지 않았거나 지도 타일이 거부되면, 위치 고르기 지도가 "지도를 불러오지 못했습니다" 대신 빈 회색 영역으로 보일 수 있다. spec 수용 기준 20과 어긋난다.
- 근거: `features/stations/kakao-maps.ts`는 `sdk.js` 스크립트 로드 실패(`onerror`)만 실패로 본다. 스크립트가 로드되고 `window.kakao.maps`가 생기면 준비된 것으로 처리한다 (2026-10-22 코드 리뷰 지적).
- 관찰: 아직 재현하지 못했다. 카카오 키 없이 확인했기 때문에 "키 없음"의 실패 안내만 실제로 확인했다.
- 다음 단계: 키를 넣은 뒤 등록되지 않은 도메인(예: `127.0.0.1:3000`)에서 열어 실제 동작과 콘솔 오류를 확인한다. 빈 지도가 재현되면 지도 생성 후 일정 시간 안에 타일이 그려지는지 등으로 실패를 감지하는 방법을 찾는다.
