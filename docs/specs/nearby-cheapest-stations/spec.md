## 사용자에게 보이는 결과

사용자가 앱을 열면 현재 위치 기준 반경 2km 안의 주유소가 선택한 기름 종류의 가격이 싼 순서로 나열된다. 현재 위치를 얻지 못하면 기본 위치인 마곡나루역 기준 목록을 바로 받고, 원하면 제목 아래 입력창의 장소 조회나 앱 안의 지도로 위치를 바꿔 같은 목록을 받는다. 각 항목에서 주유소 이름, 가격, 거리를 바로 비교할 수 있고, 항목을 누르면 카카오맵 웹에서 그 주유소의 위치를 볼 수 있다.

## 범위

- 현재 위치를 얻어 반경 2km 안의 주유소를 검색한다.
- 제목 바로 아래 입력창에 장소 이름이나 주소를 넣고 "조회"를 누르면, 그 장소를 좌표로 바꿔 주변 반경 2km 주유소를 검색한다.
- 현재 위치를 얻지 못하면 마곡나루역 기준으로 검색한다.
- "위치 바꾸기"로 앱 안의 OpenStreetMap 지도를 열어 지점을 직접 눌러 고른 뒤 검색할 수 있다. 장소 이름·주소 조회는 제목 아래 입력창 하나로만 한다.
- 기름 종류는 휘발유와 경유 중에서 고르며 기본값은 휘발유다.
- 결과는 가격이 싼 순서로 보여준다.
- 각 항목은 주유소 이름, 가격(원/L), 거리를 보여준다.
- 2km 안에 주유소가 없으면 주유소가 없다고 표시한다.
- 위치를 얻지 못해 마곡나루역 기준으로 보여 줄 때와 가격 정보를 가져오지 못했을 때를 각각 구분해 표시한다.
- 목록의 주유소를 누르면 카카오맵 웹 지도가 새 탭에서 그 주유소 위치를 표시한 채로 열린다.
- 부제목과 안내 바로 아래에 OpenStreetMap 지도를 보여 준다. 지도 정중앙에는 고정 핀이 있고, 핀 둘레에 반경 2km 원을 그린다.
- 지도를 끌어 옮기면 고정 핀 아래 지점이 바뀌고, "다시 검색"을 누르면 그 핀 위치 기준으로 주유소를 검색한다.
- 목록 위의 "지도에서 보기"를 누르면 카카오맵 웹 지도가 새 탭에서 검색 기준 위치를 표시한 채로 열린다.

## 수용 기준

1. 위치 권한을 허용한 상태로 앱을 열면, 별도 조작 없이 휘발유 기준 반경 2km 주유소 목록이 나온다.
2. 목록은 가격이 낮은 항목부터 나오며, 각 항목에 주유소 이름, 가격, 거리가 보인다.
3. 목록의 모든 주유소는 검색 기준 위치에서 2km 이내다.
4. 기름 종류를 경유로 바꾸면 경유 가격 기준으로 다시 검색되어 가격순으로 나온다. 다시 휘발유로 바꿔도 마찬가지다.
5. 현재 선택된 기름 종류가 화면에서 분명하게 보인다.
6. 2km 안에 해당 기름을 파는 주유소가 없으면 목록 대신 "주변 2km 안에 주유소가 없습니다"에 해당하는 빈 상태가 보인다.
7. 위치 권한을 거부했거나 위치를 얻지 못하면, 별도 조작 없이 마곡나루역 기준 반경 2km 목록이 나오고, 현재 위치를 알 수 없어 마곡나루역 기준이라는 안내가 보인다. 안내에서 "위치 바꾸기"(지도)와 "현재 위치로 다시 시도"를 할 수 있고, 제목 아래 입력창으로 장소를 조회할 수도 있다.
8. 가격 정보를 가져오지 못하면(오피넷 오류, 호출 한도 초과, 네트워크 실패 등), 빈 상태와 구별되는 오류 안내가 보이고 다시 시도할 수 있다.
9. 검색이 진행되는 동안 로딩 상태가 보인다.
10. 사용자는 "다시 검색"으로 검색 기준 위치에서 목록을 갱신할 수 있다. 현재 위치를 쓰는 중이면 위치를 새로 얻고, 마곡나루역이나 사용자가 정한 위치를 쓰는 중이면 그 위치로 다시 검색한다.
11. 오피넷 인증키는 브라우저에서 내려받은 어떤 응답이나 코드에도 나타나지 않는다.
12. 좁은 모바일 화면에서 이름, 가격, 거리가 잘리지 않고 읽힌다.
13. 목록의 주유소 항목을 누르면 새 탭에서 카카오맵 웹 지도가 열리고, 그 주유소의 위치와 이름이 표시된다. 목록 화면은 그대로 남는다.
14. 각 주유소 항목은 누를 수 있는 링크로 인식되며, 키보드로도 열 수 있다.
15. 위치 고르기 지도에서 한 지점을 누르면 그 자리에 마커가 놓이고, 다른 곳을 누르면 마커가 옮겨진다.
16. 마커를 놓기 전에는 "이 위치로 검색"을 누를 수 없고, 놓은 뒤 누르면 그 지점 기준 반경 2km 목록이 나온다.
17. 화면 부제목은 검색 기준이 현재 위치, 마곡나루역, 고른 위치 중 무엇인지 보여 준다.
18. 마곡나루역이나 고른 위치로 검색한 뒤 기름 종류를 바꾸거나 "다시 검색"을 누르면 같은 위치로 다시 검색한다.
19. 마곡나루역, 고른 위치, 조회한 장소로 검색 중에는 "위치 바꾸기"로 지도를 열어 다른 지점을 정할 수 있다. 현재 위치로 검색 중에는 이 버튼이 없다.
20. 지도를 불러오지 못하면(지도 라이브러리나 타일을 받지 못하는 경우 등) 지도 자리에 불러오지 못했다는 안내가 보이고, 제목 아래 입력창과 위치 권한으로 다시 시도하는 길은 그대로 남는다.
21. "위치 바꾸기" 화면에는 장소 입력창이 따로 없다. 장소 조회는 제목 아래 입력창(수용 기준 23–28)으로만 한다.
22. 목록(또는 빈 상태)이 보일 때 부제목 옆의 "지도에서 보기"를 누르면 새 탭에서 카카오맵 웹 지도가 열리고, 검색 기준 위치(마곡나루역, 현재 위치, 고른 위치)와 그 이름이 표시된다. 카카오 키 없이 동작한다.

23. 제목 바로 아래에 장소 입력창과 "조회" 버튼이 항상 보인다. 위치를 고르는 화면에서도 보이며, 거기서 조회하면 그 장소 기준 목록으로 바뀐다. 입력이 비어 있으면 조회할 수 없다.
24. 장소(예: "강남역")를 입력하고 "조회"를 누르거나 Enter를 치면, 그 장소 기준 반경 2km 주유소가 가격순으로 나오고 부제목은 "{입력한 장소} 반경 2km"가 된다.
25. 입력한 장소를 찾지 못하면 입력창 아래에 "'{입력}' 위치를 찾지 못했습니다."가 보이고, 기존 목록은 그대로 둔다. 장소 검색 서비스가 실패하면 다시 시도하라는 안내가 보인다.
26. 입력한 장소로 검색한 뒤 기름 종류를 바꾸거나 "다시 검색"을 누르면 같은 장소로 다시 검색하고, "현재 위치로 다시 시도"로 현재 위치 기준으로 돌아갈 수 있다.
27. 장소 검색 결과를 쓰는 동안 화면에 "© OpenStreetMap contributors" 저작자 표시가 보인다.
28. 장소 검색은 "조회"를 눌렀을 때만 일어나고, 입력하는 동안에는 요청하지 않는다.
29. 목록에서 주유소를 누르면 장소 검색 여부와 관계없이 카카오맵 웹으로 그 주유소 위치를 연다.

30. 검색 기준 위치가 정해지면 부제목과 안내 바로 아래에 지도가 보이고, 지도 정중앙에 고정 핀이, 핀 둘레에 반경 2km 원이 보인다. 검색 기준이 바뀌면 지도도 그 위치를 중앙에 두도록 옮겨진다.
31. 이 지도의 오른쪽 아래에 "© OpenStreetMap contributors" 저작자 표시가 항상 보인다.
32. 위치를 고르는 화면에서는 이 지도를 보여 주지 않는다. 검색 중이나 가격 오류일 때는 지도를 그대로 둔다.
33. 지도를 끌어 옮겨도 고정 핀은 지도 정중앙에 그대로 있고, 2km 원은 핀을 따라 움직인다. 옮기기만 해서는 주유소를 검색하지 않는다.
34. 지도를 옮긴 뒤에는 "다시 검색"을 누르면 핀 위치로 검색한다는 안내가 보이고, "다시 검색"을 누르면 핀 위치 기준 반경 2km 목록이 나오며 부제목은 "고른 위치 반경 2km"가 된다.
35. 지도를 옮기지 않은 채 "다시 검색"을 누르면 수용 기준 10대로 지금 검색 기준으로 다시 검색한다.

## 확정된 제약과 근거

- 반경은 2km로 고정한다. 사용자가 반경을 바꾸는 기능은 없다. — PRODUCT.md의 범위다.
- 기름 종류는 휘발유와 경유 둘뿐이다. — PRODUCT.md에서 확정했다. 고급휘발유, 등유, LPG는 다루지 않는다.
- 가격 데이터는 오피넷에서만 가져온다. — fuel-price-source 결정을 따른다.
- 주유소 위치와 검색 기준 위치는 외부 웹 지도(카카오맵 `map.kakao.com/link/map`)로 연다. 지도 앱 실행은 하지 않는다. — 사용자가 2026-10-22에 정했다. 키 없이 동작한다.
- 검색 위치를 보여 주는 지도는 OpenStreetMap 타일을 Leaflet으로 띄운다. — 사용자가 2026-10-22에 키 없이 바로 뜨는 쪽으로 골랐다. map-provider 결정을 따른다.
- "위치 바꾸기"에서 지점을 눌러 고르는 지도도 OpenStreetMap 타일을 Leaflet으로 띄운다. 앱 어디에서도 카카오 API 키를 쓰지 않는다. — 사용자가 2026-10-22에 키 없이 동작하도록 정했다.
- 앱을 열면 버튼 없이 바로 검색한다. 운전 중 조작을 줄이기 위해서다. — 사용자가 2026-10-22 리뷰에서 오피넷 하루 300회 호출 한도를 알고도 유지하기로 정했다.
- 거리는 1km 미만이면 m 단위로, 1km 이상이면 소수점 한 자리 km(반올림)로 표시한다. 2km 경계 근처(예: 1,976.9m → "2.0km")도 같은 규칙을 따른다. — 사용자가 2026-10-22 리뷰에서 목록 안의 단위를 섞지 않는 쪽으로 정했다.
- 선택된 기름 종류 표시는 shadcn 토글의 기본 선택 모양으로 충분하다. — 사용자가 2026-10-22 리뷰에서 확인했다(수용 기준 5).
- 제목 아래 장소 검색은 OpenStreetMap Nominatim 공개 서버를 서버 경로에서 호출해 좌표로 바꾼다. — 사용자가 2026-10-22에 카카오 로컬 REST API 대신 골랐다. place-search 결정을 따른다.
- 운전 중 조작에 대한 별도 경험 원칙은 두지 않는다. — 사용자가 2026-10-22에 정했다.
- 현재 위치를 얻지 못하면 마곡나루역을 기본 위치로 바로 검색한다. — 사용자가 2026-10-22에 정했다.

## 가정 (바꿀 수 있음)

- 가격이 같으면 가까운 주유소를 먼저 보여준다.
- 가격은 원 단위에 천 단위 구분 기호를 붙여 표시한다(예: 1,689원).
- 2km 안의 주유소를 개수 제한 없이 모두 보여준다.
- 검색 위치 지도에는 정중앙 고정 핀과 2km 원만 그리고, 주유소 핀은 그리지 않는다. 지도는 드래그와 확대 버튼으로 움직일 수 있고, 마우스 휠 확대는 페이지 스크롤과 겹치지 않게 끈다. 핀을 세밀하게 맞출 수 있도록 손을 뗀 자리에서 바로 멈추게 관성을 끈다.
- 위치를 계속 따라가며 자동으로 갱신하지는 않는다. 갱신은 "다시 검색"으로 한다.
- 오피넷이 좌표를 주지 않은 주유소는 목록에 그대로 보여 주되 누를 수 없다(지도 링크 없음).
- 지도 링크의 이름에 들어간 쉼표는 공백으로 바꾼다. 카카오맵 링크에서 쉼표가 이름과 좌표를 나누는 구분자이기 때문이다.
- 위치 고르기 지도의 처음 중심은 마곡나루역이다.
- 고른 위치는 새로고침하면 잊는다. 새로고침하면 현재 위치부터 다시 시도한다.
- 기본 위치로 검색 중이라는 안내는 부제목 아래 한 줄로 두고, "위치 바꾸기"와 "현재 위치로 다시 시도"는 그 옆의 작은 버튼으로 둔다.
- 위치를 얻지 못한 뒤에는 기름 종류 전환과 "다시 검색"이 위치를 다시 묻지 않고 마곡나루역을 쓴다. 위치를 다시 얻으려면 "현재 위치로 다시 시도"를 누른다.
- 마곡나루역 좌표는 역 출입구 부근의 대략 좌표(37.5668, 126.8270)다. 반경 2km 검색에서 수백 m 오차는 결과에 거의 영향이 없다.
- 장소 조회 결과가 여러 개면 첫 번째를 쓰고, 조회하면 바로 그 장소 기준으로 주유소를 검색한다.

## 범위 밖

- 앱 안 지도에 주유소 핀 찍기, 지도 앱 실행, 길 안내, 주유소 상세 페이지 — 주유소 위치 확인은 외부 웹 지도(카카오맵)에 맡긴다.
- 조회 결과 여러 개 중에서 고르는 목록, 자동 완성 — 요청되지 않았다.
- 현재 위치로 검색 중일 때 다른 위치로 바꾸기 — 요청된 것은 위치를 얻지 못했을 때의 대안이다.
- 즐겨찾기, 가격 알림, 검색 기록 — 요청되지 않았다.
- 계정과 로그인 — 핵심 흐름에 필요하지 않다.
- 반경 변경과 정렬 기준 변경 — 2km와 가격순은 제품의 고정 범위다.

## 미뤄둔 결정

- 가격 정보의 최신성 기준 — PRODUCT.md에서 미정으로 남겼다. 임시 동작(interim): 오피넷이 주는 현재 가격을 그대로 보여주고, 최신성 표시는 하지 않는다.

## 남은 위험

- 오피넷 일반 API의 하루 호출 한도는 300회다. 자동 검색과 기름 종류 전환은 각각 호출을 쓰므로, 여러 사람이 쓰면 한도에 닿아 오류 상태가 자주 보일 수 있다.
- 오피넷은 KATEC 좌표를 쓴다. 변환이 어긋나면 엉뚱한 지역이 검색되거나 지도의 핀이 실제 주유소와 떨어져 보인다.
- 위치 정보는 보안 연결(HTTPS 또는 localhost)에서만 동작한다.
- Nominatim 공개 서버는 앱 전체 합계 초당 1회까지만 허용하고, 사전 고지 없이 접근을 막을 수 있다. 여러 사람이 쓰거나 상용으로 쓰면 다른 지오코딩 서비스로 바꿔야 한다.
- Nominatim은 국내 장소 검색이 카카오보다 약하다. 예를 들어 "강남역"은 역 대신 약 400m 떨어진 같은 이름의 버스정류장이 첫 결과로 나온다(2026-10-22 확인).
- OpenStreetMap 표준 타일 서버는 사용량 보장이 없고, 과도하게 쓰면 예고 없이 막힐 수 있다. 여러 사람이 쓰거나 상용으로 쓰면 다른 타일 제공자로 바꿔야 한다.
