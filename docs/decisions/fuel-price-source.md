# 유가 데이터 출처

## Decisions

- 주유소 가격과 반경 내 주유소 목록은 한국석유공사 오피넷 유가정보 API에서 가져온다. 반경 검색은 `aroundAll.do`(기름 종류 `prodcd`, 반경 `radius`, 가격순 `sort=1`)를 사용한다.
- 오피넷 인증키(`certkey`)는 사용자 화면이나 브라우저로 내려보내지 않는다.

## Boundaries

- 가격 데이터에 대한 결정이다. 지도 표시나 길 안내가 필요해질 때 쓸 위치·지도 서비스는 정하지 않았다.
- 오피넷 응답 좌표는 KATEC이므로, 브라우저 위치(WGS84)를 쓰는 곳에서는 좌표 변환이 따라온다.

## Why

국내 주유소 판매가격을 공식으로 집계해 무료로 제공하고, 반경 검색·기름 종류 구분·가격순 정렬을 API가 직접 해 준다. 다른 출처는 가격 자체를 주지 않는다.

## Reconsider when

- 하루 호출 한도(일반 API 300회, 제휴 시 1,500회)가 실제 사용량을 지속적으로 막을 때
- 오피넷이 반경 검색 API를 중단하거나 무료 제공 조건을 바꿀 때

## Still-rejected alternatives

- 카카오 로컬 API 카테고리 검색(`OL7`) — 주유소 위치와 거리는 주지만 유가 정보가 없어 가격순 목록을 만들 수 없다; 카카오가 유가를 제공하게 되면 재검토.

## Evidence worth preserving

- 2026-10-22 확인: 오피넷 일반 API 인증키는 웹사이트 "일반 API 이용 신청"(`/user/custapi/custApiNew.do`)에서 자동 승인으로 즉시 발급된다. 오피넷은 공식 agent skill, `llms.txt`(404), MCP 서버를 제공하지 않는다.
