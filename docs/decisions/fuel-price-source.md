# 유가 데이터 출처

## Decisions

- 주유소 가격은 오피넷이 제공하는 "현재 판매가격(주유소)" CSV 파일(전국 개별 주유소, CP949)에서 가져온다. 앱은 실행 중에 오피넷 API를 부르지 않는다.
- CSV에는 좌표가 없으므로, 데이터를 갱신할 때 스크립트(`bun run stations:build`)가 주소를 위도·경도로 바꿔 `data/stations.json`을 만든다. 기본은 키가 필요 없는 OpenStreetMap Nominatim이고, `KAKAO_REST_API_KEY`가 있으면 카카오 로컬 API를 쓴다.
- Nominatim은 사용 정책대로 한 번에 하나씩, 1초 넘게 간격을 두고, 앱을 밝히는 User-Agent로 묻는다. 주소로 찾은 결과가 도로 단위면 주유소 이름과 지역으로 다시 찾고, 행정구역 단위 결과는 쓰지 않는다.
- 스크립트는 `--region`으로 지역을 좁힐 수 있다. 2026-10-22 기준 데이터는 `--region 서울`로 만든 서울 388곳이다.
- 찾은 좌표는 주유소 ID별로 `data/station-coords.json`에, 못 찾은 주소는 `data/station-coords-missed.json`에 저장해 같은 질의를 반복하지 않는다. 못 찾은 주유소는 데이터에서 뺀다.
- 반경 2km 검색과 가격순 정렬은 앱 서버가 `data/stations.json`으로 직접 계산한다.

## Boundaries

- 가격은 CSV를 받은 날 기준이다. 화면에 그 기준일을 보여 준다. 최신 가격이 필요하면 CSV를 다시 받아 스크립트를 돌리고 배포한다.
- 지도 표시는 map-provider 결정을, 사용자가 입력한 장소의 좌표는 place-search 결정을 따른다. 카카오 API는 주유소 주소를 좌표로 바꾸는 데에만 쓴다.

## Why

사용자가 앱 실행과 배포에 키가 필요 없고 호출 한도도 없는 방식을 골랐다(2026-10-22). CSV는 좌표가 없어 주소를 좌표로 바꿔야 한다. 카카오 로컬 API가 더 정확하지만 키가 필요해, 사용자가 키 없는 Nominatim을 골랐다(2026-10-22). 정확도가 낮다는 점(아래 근거)을 알고 정한 것이다.

## Reconsider when

- 가격이 하루 이상 늦어서 실사용에 문제가 된다는 근거가 쌓일 때
- 오피넷 CSV의 열 구성이나 제공 방식이 바뀔 때
- 오피넷 CSV에 좌표가 포함되기 시작할 때

## Still-rejected alternatives

- 오피넷 유가정보 API(`aroundAll.do`) — 실시간 가격과 반경 검색을 주지만 인증키와 하루 300회 호출 한도가 필요하다; 실시간 가격이 꼭 필요해지면 재검토.
- 카카오 로컬 API로만 지오코딩 — 국내 주소를 건물 단위로 찾지만 REST API 키와 [카카오맵] 사용 설정이 필요하다; 정확도가 실사용에 부족하면 `KAKAO_REST_API_KEY`를 넣고 다시 돌린다.
- 시·군·구 단위 검색 — 좌표 없이 가능하지만 반경 2km와 거리 표시를 포기해야 한다.

## Evidence worth preserving

- 2026-10-22 받은 CSV: 열은 `고유번호, 지역, 상호, 주소, 상표, 셀프여부, 고급휘발유, 휘발유, 경유, 실내등유`, 10,258곳(빈 줄 제외), CP949 인코딩, 따옴표 없음. 판매하지 않는 기름은 가격이 0이다(휘발유 0인 곳 55곳, 경유 0인 곳 21곳). 고유번호는 오피넷 API의 `UNI_ID`와 같은 형식(예: `A0000035`)이다.
- 오피넷 다운로드 페이지(`/user/opdown/opDownload.do`)는 접속 대기열(NetFunnel)과 로그인을 거쳐야 해서 사람이 브라우저로 받는다.
- 2026-10-22 Nominatim 표본: 주소만 물었을 때 20곳 중 13곳을 찾았고 모두 도로 단위였다. 도로 단위일 때 이름으로 다시 찾게 바꾼 뒤 다른 표본 20곳에서 정확한 지점 6곳, 도로 단위 8곳, 못 찾음 6곳이었다.
- 카카오 로컬 API 일간 무료 쿼터: 주소로 좌표 변환 100,000건, 키워드로 장소 검색 100,000건. 2024-12-01부터 새로 쓰는 앱은 [카카오맵] 사용 설정을 켜야 한다.
